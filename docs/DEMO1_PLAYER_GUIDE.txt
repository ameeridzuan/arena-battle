DEMO 1 - ArenaBattle Team Lobby + Character Skills (27 October 2026)
Windows x64. No installation or Godot setup needed.

1. Extract the ENTIRE ZIP to a folder. Keep Demo 1.exe and Demo 1.pck together.
2. All players run Demo 1.exe from their extracted copies.
3. Host clicks "Host lobby (up to 4 players)". Share the host PC's LAN IPv4 address.
4. Friends enter that IP and click "Join host". Everyone must use this same build.
5. In the waiting lobby, choose Team A/Blue or Team B/Orange and a character.
6. Each player clicks Ready. The host then clicks Start 1v1, 2v1/1v2, or 2v2.
   Only two players are required, with at least one per team. Max two per team.
   Empty slots stay empty; there are no bots. Five kills or three minutes ends it.
   Joining, leaving or changing a selection clears Ready for everyone.
   If the host leaves, return to menu and create a new lobby. No host migration.

Use your own trusted LAN/Wi-Fi. If Windows asks, allow Demo 1 on your private
network. UDP port 24560 must reach the host. Guest Wi-Fi may isolate devices.
127.0.0.1 means this same computer; a friend on another PC needs your LAN IP.
If several addresses appear, use the active Wi-Fi/Ethernet address (ipconfig).
This build has no matchmaking, authentication, internet relay, or NAT traversal.
Different homes are not plug-and-play. Do not disable a firewall to connect.
Office-managed PCs remain subject to workplace software/network policies.

WASD move, Shift run, Space jump / wall jump, mouse look.
E grabs/climbs a ledge; A/D shimmy; C drops.
Left click: timed blade attack; jump + left click: overhead attack.
Q + forward: dash; Q + side/back: dodge; Q alone: backstep.
F: timed frontal melee parry (does not block spells). V: aim view; R: fire spell (20 impact + 3 burn x 3).
G: character skill. Arclight throws Pulse Grenade (4-second enemy stun, 18-second cooldown).
Ashen Warden equips Flame Scythe for 20 seconds (40-second cooldown); hits inflict burn.
The HUD shows skill cooldown and remaining weapon duration.
Tab: switch Arclight / Ashen Warden. All players see the same selected character.
Esc releases/re-captures the cursor.

NEW TERRAIN: blue/amber terraces on the sides have 1.8 m climbable faces
and varied-height stair approaches. The north/south routes contain opposing
walls for alternating wall jumps, with elevated landing platforms. Low blocks
provide vault routes; the central court stays open for dueling.
Press Esc to click "Return to menu" for another match.
Closing the host or returning to menu stops its background server.
Closing a client ends a running session. Restart/return to menu for a new match.

If hosting fails, close any previous host using UDP 24560 and try again.
Server log: %APPDATA%\Godot\app_userdata\Demo 1\demo1-server.log

This unsigned preview uses the installed Godot 4.7.2 Windows executable as a
portable runtime with a separately exported resource pack. It is larger than
a template-based release build, but no editor installation is required.
Godot's executable metadata/icon remain present. Engine licenses accompany it.

Choose Arclight or Ashen Warden in the lobby; teammates may use the same character.
Tab switches during play remain server-approved and replicated to all clients. Movement, blade contacts,
parry windows, cooldowns, spell/burn damage and scoring run on the server.
This is a playtest preview; human LAN/feel acceptance remains separate.
