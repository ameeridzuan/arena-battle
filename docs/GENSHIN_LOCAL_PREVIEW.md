# Local Genshin concept preview

Run `tools/start_genshin_local_preview.ps1` with PowerShell. An optional `-GodotPath` accepts a different Godot executable. The launcher opens `scenes/characters/GenshinLocalArena.tscn` in the existing parkour arena with the existing player controller.

Controls: WASD moves, Shift runs, Space jumps, left mouse attacks, mouse orbits, V changes the aim camera, F2 switches front/back view, Home resets position, and Escape releases the cursor. Tab compares the concept model with Arclight and Ashen Warden. F3 cycles the 49 animation clips in place; F4 returns to gameplay. Pass `-Showcase` to the launcher to start a running loop immediately.

The concept character now has a 299-bone skinned rig, preserved source weights and 49 retargeted clips. The existing controller selects idle, directional walking, running and jumping; accepted melee attacks use the upper-body action layer. A local animation-driver subclass preserves the retargeted clips instead of replacing them with libraries for other skeletons. Split coat tails have separate weighted bones. The original static GLB and Blender appearance scene remain available.

Combat variants, dodges, blocks, casting, hits and traversal clips can be reviewed with F3. This selector previews animation only; it does not implement traversal, spell or dodge gameplay. This is a first animation pass, with five rendered pose samples reviewed rather than a full clothing-clearance audit over every frame. It is an unscored local test, so the existing Combatant warning about a missing match manager is expected. The production roster, main scene and multiplayer setup are unchanged by this preview.

The loader reads `../assets/characters/protagonist/genshin-concept-match/protagonist-local-styled.glb` relative to the Godot project. The restricted model stays outside `res://`, so normal project exports do not package it. The preview requires this workspace asset and is not a distributable game feature. Model credit: miHoYo; MMD conversion: 观海 / 观海子. Source terms and provenance are in the adjacent character study README and `genshin-study/SOURCE.json`. The source prohibits commercial use and redistribution.

Validation: `tests/integration/genshin_local_preview_test.gd` passed 124 checks covering GLB loading, skins, clips, scale, feet, movement-driven gait selection, jumping, attack-layer acceptance, gallery controls, collision, health and model switching. Every clip was sampled twice to check finite bounded bone transforms and changing rotations. Rendered Idle, Walk, Run, Jump and Attack_Slash samples are saved beside the GLB as `animation-*.png`. Rebuild the animation asset through Blender MCP with `../animate_genshin_concept.py`; the file preserves the appearance source and authored source actions. `animation-manifest.json` records all 49 clips.

The subsequent hand/style pass (`../style_genshin_run.py`) authors compact forward/back arm swings, a forward torso lean, shoulder counter-rotation and a steadier head. Walking and idle use a relaxed arm stance. Wrist directions align to the forearms, and articulated fingers replace rigid flat hands across the clip library. Pre-style actions are preserved as `BeforeHandStyle|...` inside the Blender file; repeat runs restore those originals before applying the pass. The style script exports `protagonist-local-styled.glb` and `protagonist-genshin-styled.blend`. It can run in a separate background Blender process with `GENSHIN_STYLE_OUTPUT` pointing to a candidate directory.

The two extra checks sample 12 points across the sprint, requiring elbow lateral displacement below 6.5 cm and hand/forearm direction dot products above .96. Blender spot samples measured approximately 2.3 cm displacement and 1.0 wrist alignment. Front, side and three-quarter renders were reviewed. `hand-style-review.json` records the style pass, and `in-game-styled-run.gif` shows its exported game playback.
